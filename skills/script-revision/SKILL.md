# Script revision

## Inputs and deliverable

- Accept: draft; intent; desired audience; constraints.
- Produce: prioritized issue log and revision plan with affected scenes.
- If critical inputs are missing, state assumptions, distinguish planning from observed footage, and mark any untestable decision for review. Do not invent measurements, assets or runtime results.

## Decision procedure

1. Read the whole draft before line editing; reconstruct premise, major choices, climax and final change from what is actually written.
2. Audit each scene for purpose, conflict, mood, information, subtext, entry and exit state.
3. Identify upstream problems before symptoms; a weak climax may require earlier stakes or setup, not a longer ending.
4. Prioritize structural revisions, then scene order, character behavior, dialogue and presentation; state dependencies.
5. Compare revised and original versions against the creative brief; preserve intentional style rather than automatically flattening unusual scenes.

## Diagnose and correct

Avoid polishing dialogue in a scene that should be removed. A nonconventional plot is not a defect unless it fails its intended experience.

## Output checks

- Deliver the specified artifact, with decisions tied to identifiable scenes, beats or shots when relevant.
- Show evidence or reasoning for the selected approach and at least one plausible alternative when the decision is consequential; state whether it is planned or actually observed.
- Verify the specific failure mode above is not present, or document the creative reason and the test that would demonstrate success.
- Use the original practice case below to check that the procedure produces a concrete, reviewable result rather than a definition or generic advice.

## Practice case

A script repeats three similar reconciliation attempts; identify what changes in each and consolidate or redesign redundant beats.
