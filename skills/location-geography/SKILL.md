# Location geography

## Inputs and deliverable

- Accept: location brief; actions; cameras; source positions.
- Produce: top-view layout, landmark map, axis and camera possibilities.
- If critical inputs are missing, state assumptions, distinguish planning from observed footage, and mark any untestable decision for review. Do not invent measurements, assets or runtime results.

## Decision procedure

1. Draw a simple top-view plan including entrances, windows, major furniture, light sources and fixed landmarks.
2. Mark actor paths and visibility relationships; decide which spatial facts the audience needs to learn.
3. Select establishing and reverse compositions that share recognizable geometry; preserve offscreen directions.
4. Check camera access, framing, backgrounds, lighting and occlusions from each position; use alternate coverage for physically impossible setups.
5. Keep one canonical plan and update revisions explicitly; generated or virtual locations should derive from this same geometry.

## Diagnose and correct

Do not invent a different window or doorway in every angle. Reconcile all views with the canonical layout or label a new location.

## Output checks

- Deliver the specified artifact, with decisions tied to identifiable scenes, beats or shots when relevant.
- Show evidence or reasoning for the selected approach and at least one plausible alternative when the decision is consequential; state whether it is planned or actually observed.
- Verify the specific failure mode above is not present, or document the creative reason and the test that would demonstrate success.
- Use the original practice case below to check that the procedure produces a concrete, reviewable result rather than a definition or generic advice.

## Practice case

A cafe conversation cuts from table to entrance and reverse singles; verify the door and windows remain on the same world sides.
