# Camera movement intent

## Inputs and deliverable

- Accept: shot intent; action; space; timing; available tools.
- Produce: movement decision with path, motivation, alternative and end frame.
- If critical inputs are missing, state assumptions, distinguish planning from observed footage, and mark any untestable decision for review. Do not invent measurements, assets or runtime results.

## Decision procedure

1. State what the move reveals, follows, reframes or changes emotionally; compare a static frame and a cut-based alternative.
2. Choose movement type according to geometry: pan/tilt rotates viewpoint, tracking translates it, zoom changes framing without camera translation.
3. Specify start and end framing, speed changes, focus target and subject behavior.
4. Check that the move preserves important content and does not introduce unmotivated disorientation.
5. Plan coverage or an edit point in case a demanding move fails.

## Diagnose and correct

Movement added merely to look cinematic can dilute tension; remove or slow it when stillness better communicates the beat.

## Output checks

- Deliver the specified artifact, with decisions tied to identifiable scenes, beats or shots when relevant.
- Show evidence or reasoning for the selected approach and at least one plausible alternative when the decision is consequential; state whether it is planned or actually observed.
- Verify the specific failure mode above is not present, or document the creative reason and the test that would demonstrate success.
- Use the original practice case below to check that the procedure produces a concrete, reviewable result rather than a definition or generic advice.

## Practice case

A character reads a letter; compare a static hold, push-in, and cut to detail, then select based on the reveal.
