# Agent use protocol

1. Read TAXONOMY.md or query registry/skills.json to choose the smallest useful set of capabilities.
2. Read the selected SKILL.md files, not the entire library. Load source notes when provenance or an exception is important.
3. Establish the creative objective and available evidence. Use optional shared schemas for stable scene/shot/asset IDs and handoffs.
4. Apply the procedure to the specific project. Preserve alternatives and explain decisions; do not treat film conventions as universal laws.
5. Test the outputs using the skill checks. If playback, visual inspection, sound or runtime evidence is unavailable, mark conclusions as provisional. Do not fabricate tests or observations.
6. Compose workflows only as needed. Related skills are optional; no required model, API, orchestrator or agent count. Platform-specific integrations belong in adapters/.
7. Preserve source attribution and rights. Do not distribute the books or their original diagrams.
