# Integrated script to screen

**Input:** Creative seed or approved script and production constraints.

**Output:** An approved narrative, design bible, shot plan, capture/generation plan and reviewed edit.

## Procedure

1. [Premise and logline](../skills/premise-and-logline/SKILL.md) — Confirm creative objective.
2. [Story architecture](../skills/story-architecture/SKILL.md) — Establish causal and emotional beats.
3. [Scene construction](../skills/scene-construction/SKILL.md) — Define scene outcomes.
4. [Production design brief](../skills/production-design-brief/SKILL.md) — Coordinate world and design.
5. [Directorial interpretation](../skills/directorial-interpretation/SKILL.md) — Determine viewpoint and staging.
6. [Storyboard design](../skills/storyboard-design/SKILL.md) — Visualize and test alternatives.
7. [Motivated lighting](../skills/motivated-lighting/SKILL.md) — Design the light world.
8. [Coverage planning](../skills/coverage-planning/SKILL.md) — Plan edit-ready material.
9. [Camera preflight](../skills/camera-preflight/SKILL.md) — Test the actual capture or implementation method.
10. [Editing rhythm](../skills/editing-rhythm/SKILL.md) — Assemble and refine timing.
11. [Creative quality audit](../skills/creative-quality-audit/SKILL.md) — Review and revise with evidence.

## Approval gate

Gate each phase: story, design, previsualization, feasibility, capture, edit, review. Select only the additional specialized skills required by the project.

Record assumptions, versioned artifact IDs, approved state and unresolved risks at every handoff. The order is a default; iterate when a later test exposes an upstream problem.
