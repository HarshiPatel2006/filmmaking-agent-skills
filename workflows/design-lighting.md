# Design a lighting system

**Input:** Scene intent, canonical set, characters and camera plan.

**Output:** World-space light plan, portrait/atmosphere variations and continuity ledger.

## Procedure

1. [Lighting intent](../skills/lighting-intent/SKILL.md) — Define the information and emotional key.
2. [Motivated lighting](../skills/motivated-lighting/SKILL.md) — Map sources and ambient behavior.
3. [Subject separation](../skills/subject-separation/SKILL.md) — Control tonal layering.
4. [Portrait lighting](../skills/portrait-lighting/SKILL.md) — Test faces from required angles.
5. [Lighting continuity](../skills/lighting-continuity/SKILL.md) — Compare every recurring setup.

## Approval gate

Add specialist atmosphere skills only when relevant. Reject lighting plans that depend on impossible source direction or unsafe historical equipment.

Record assumptions, versioned artifact IDs, approved state and unresolved risks at every handoff. The order is a default; iterate when a later test exposes an upstream problem.
