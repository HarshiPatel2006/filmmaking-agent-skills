# Storyboard to edit

**Input:** Script or beat map, format and provisional audio.

**Output:** Ordered boards, timing plan, coverage list, edit map.

## Procedure

1. [Storyboard design](../skills/storyboard-design/SKILL.md) — Plan key compositions and action.
2. [Camera angle projection](../skills/camera-angle-projection/SKILL.md) — Check spatial feasibility if geometry matters.
3. [Animatic and shot flow](../skills/animatic-and-shot-flow/SKILL.md) — Time the panels and test flow.
4. [Coverage planning](../skills/coverage-planning/SKILL.md) — Identify required alternate views.
5. [Editing rhythm](../skills/editing-rhythm/SKILL.md) — Refine shot durations.
6. [Shot flow audit](../skills/shot-flow-audit/SKILL.md) — Inspect boundaries and revise.

## Approval gate

Use an animatic before committing expensive resources; distinguish provisional timecodes from verified timing.

Record assumptions, versioned artifact IDs, approved state and unresolved risks at every handoff. The order is a default; iterate when a later test exposes an upstream problem.
