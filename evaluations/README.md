# Evaluation protocol

The case catalog contains one original test per skill. Cases are unexecuted behavioral evaluations, not benchmark results. To test, supply the case to the same agent once without the skill and once with only the relevant skill and source notes. Hold other context and tools constant. Blind-review the resulting artifacts against each case's acceptance criteria and the rubric below. Repeat across at least two agents and multiple runs before claiming improvement.

Score each dimension 0 (absent/incorrect), 1 (partial), or 2 (specific and usable): task completion, creative decision quality, technical/spatial coherence, handling of exceptions, evidence and honesty, and output usability. Require no critical failure: fabricated observations, unsafe practice, inconsistent mandatory continuity, missing primary output, or unauthorized source reproduction. Do not report scores until the runs exist. Static validation is separate.
